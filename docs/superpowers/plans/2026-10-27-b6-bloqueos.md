# B6 — Bloqueos: menú simplificado y "Baja médica" — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El desplegable de Citas queda en cinco acciones con un submenú de tipos de bloqueo que solo ven agentes y psicólogos con permiso, y "Baja laboral" pasa a llamarse "Baja médica" en app, base y Make.

**Architecture:** La composición del menú vive en un módulo puro `lib/acciones-menu.ts` con tests; la página de Citas solo mantiene dos estados (`accionMenu`, `tipoBloqueo`) y deriva `accion` con `accionReal`, así el resto del formulario y el envío a Make no cambian. El renombrado es una migración idempotente más una búsqueda literal en el código.

**Tech Stack:** Next.js + TypeScript, Vitest, Supabase SQL Editor, Make (a mano).

**Spec:** `docs/superpowers/specs/2026-10-27-b6-bloqueos-design.md`. Tablero: `docs/backlog-2026-10-21.md` (B6: 34, 35). Método: `docs/metodo-trabajo.md`.
